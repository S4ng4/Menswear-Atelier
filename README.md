# Atelier — Timeless Menswear

Premium editorial menswear platform. Compose outfits, explore a curated lookbook, and learn classic style rules.

**Not an e-commerce store** — an editorial lookbook experience.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- Zustand (persisted builder + favorites)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint
